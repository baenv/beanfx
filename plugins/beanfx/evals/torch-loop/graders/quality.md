The reply delivers one finished looping effect made in one pass. Pass only when all of these hold:

- A brief of about 6 lines appears before the result and keeps the values the prompt fixed: 32x48, 12 frames, 12 fps, a loop, soft painterly, strong glow.
- The reply shows research on how a real flame moves or changes colour (findings with links).
- The reply gives the path of the preview page (an .html file under out/) and of the gif.
- The reply says the checks passed, the loop seam check included, or names each check that still fails.
- The reply ends with a list of 3 to 5 suggested upgrades, each naming a part or knob, a value and a reason, and none of them is already applied.
- The agent did not run a benchmark, shape takes or glow takes, and did not polish in repeated look-and-fix rounds.
